description: Starts a session on a handover — read it, plan, close the open points (no deferral).
---

Lies die Übergabe `$ARGUMENTS` (die jüngste zur Linie). Nenne die offenen
Punkte und plane das Atom.

Dann arbeite die Punkte ab — so viele wie möglich; Sub-Agenten tragen eigenen
Kontext, die Anzahl ist kein Aufwand. Keine neuen Register, keine Befunde, kein
Aufschieben: eine umsetzbare Erkenntnis wird gebaut, nicht abgelegt. Erledigtes
wird aus der Übergabe gelöscht — git trägt, was gemacht wurde.

Nur eigene Arbeit: bei geteilten Dateien nur die eigenen Hunks; committet wird
nur der eigene Teil, fremde uncommittete Arbeit wird nie überschrieben; gepusht
wird erst, wenn der Baum ruhig ist und das Wort kommt.
