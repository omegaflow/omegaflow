# Verhalten

Volltext des Contributor Covenant 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Dieses Haus folgt ihm. Dazu vier eigene Sätze, weil die Arbeit hier anders
aussieht als in einem gewöhnlichen Repository:

1. **Ein Befund ist keine Beleidigung.** Wer eine Zahl anzweifelt, zweifelt die
   Zahl an, nicht die Person. Wer sie belegt, hat recht — unabhängig davon, wer
   sie genannt hat.
2. **„Später" ist eine Antwort, die zählt.** Ein offener Punkt wird benannt,
   nicht stillschweigend liegengelassen; sonst trägt ihn die nächste Sitzung.
3. **Fünf Linien, ein Haus.** Der fremde Punkt wird als direkter Edit des
   Eigentümers geführt, und beide Enden werden benannt. Kein Schreiben über
   Köpfe hinweg.
4. **Der Rat entscheidet, die Linie führt.** Wer eine Grenze ändern will, geht
   über `rat/`; wer sie überschreitet, sagt es.
