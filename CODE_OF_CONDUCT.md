# Code of conduct

The full text of Contributor Covenant 2.1 applies:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Four sentences of our own, because the work here looks different from a
common repository:

1. **A finding is not an insult.** Whoever questions a number questions the
   number, not the person. Whoever backs it with evidence is right, whoever
   named it first.
2. **"Later" is an answer that counts.** An open point is named, not left
   quietly; otherwise the next session carries it.
3. **A foreign point is an edit of its owner.** No writing over heads; both
   ends are named.
4. **A limit changes by decision, not by drifting.** Whoever wants to move one
   says so and gives the reason.

## Enforcement

Reports go to the maintainers through
https://github.com/omegaflow/omegaflow/security/advisories/new, private like a
security finding. An answer follows within seven days.
