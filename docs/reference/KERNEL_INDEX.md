## Moon PCK finding (session 2026-08-14)
The moon text PCKs (ssd.jpl.nasa.gov/ftp/misc/pck/
pck.sat441/pck.jup365/pck.mar099/pck.ura182/pck.plu060, each .tpc) carry
RADII + POLE for the moons but NO J2/J4 values — the only hits are
comment lines (BODYnnn_JCOEF documentation). Moon harmonics from text PCKs
therefore manifest 0 (no fabrication). Real zonal terms live in
the binary PCKs (moon_pa_de440, satellite .bpc) — that is K02. pck00010.tpc
covers Phobos/Triton/Charon with POLE+RADII; the GM of all bodies comes from
gm_Horizons.pck (km³/s², parser scales ×1e9).
