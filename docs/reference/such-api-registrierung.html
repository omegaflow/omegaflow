Such-APIs — Registrierung und Keys

Stand 2026-10-21. Gemessen mit curl -sL -o /dev/null -w '%{http_code}' und Browser-User-Agent.

403/429 heißt erreichbar, aber Bot-Schutz — kein toter Host. 000/404/410 heißt tot, eingestellt oder falsche Route.

200 202/203/307 403/429 Bot 000/404/410 tot
Eigener Status pro Zeile: Die Checkbox springt bei jedem Klick offen → registriert → authentifiziert → declined → offen. Gespeichert wird lokal im Browser (localStorage), nicht im Repo.
Standardansicht: kostenpflichtige Dienste, Dienste mit bereits funktionierendem Key und Dienste, deren Signup eine Kreditkarte verlangt, sind ausgeblendet (Toggles oben). Sichtbar bleibt, was gratis ist, ohne Karte auskommt und noch keinen funktionierenden Key hat.
Neu gebaut und live (keyless): --hn, --openverse, --nasa-images, --artic. Alle vier antworten mit 200; archive_search --all nimmt sie automatisch mit.
