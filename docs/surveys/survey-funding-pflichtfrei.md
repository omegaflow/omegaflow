# Funding & Support ohne Pflicht — Erkundung

Kriterium: Wege, die **keine Release-, Publikations- oder Gegenleistungspflicht**
erzeugen. Die Schwester-Erkundung `survey-funding-erkundung.md` sammelt die
Pflicht-Programme (Stiftungen); dieses Blatt hält nur die druckfreien.

## A. Spenden / Sponsoring — keine Gegenleistung
GitHub Sponsors, Open Collective, Patreon, Ko-fi, Liberapay, Buy Me a Coffee,
PayPal.me. Setup: `.github/FUNDING.yml` + README-Abschnitt (Commit `78dbeb01`).
Ohne Publikum ≈ 0 € — der Ertrag folgt der Sichtbarkeit, nicht dem Setup.

## B. Kostenlose API-Tiers
Gemini (AI Studio), Groq, Cerebras, NVIDIA NIM, Cloudflare Workers AI, Mistral,
Cohere, Z.ai/GLM, OpenRouter, Hugging Face. Direkter Kosten-Offset; Keys sind
Konto-Sache (nie getrackt).

## C. Kostenlose Compute / CI
GitHub Actions (öffentliche Repos), Google Colab, Kaggle (GPU), Codespaces
(Freistunden), Cloudflare Workers/Pages.

## D. Infrastruktur-Support
Cloudflare (DNS/CDN/Workers), jsDelivr, Resend (Mail), GitHub Pages.

## E. Hardware — kein Release, aber oft org-fokussiert
- **Framework**: Sponsoring-Formular nominiert **Organisationen** für
  Open-Firmware/-Hardware **rund um Framework-Produkte** → nicht passend.
- **Tuxedo Computers**: Sponsoring für **Linux-, Open-Source- und
  Gemeinschaftsprojekte** (Sachspenden, finanzielle Unterstützung, Leihgeräte);
  Kontakt nur über Formular (`tuxedocomputers.com/de/Kontakt.tuxedo`) → passend,
  Kanal ist ein Formular.
- **System76**: YouTube-/Marketing-Sponsoring und Support-Tickets → nicht passend.
- Refurb/gebraucht als günstigere Alternative.

## F. Steuer — kein Release
Sind die LLM-Kosten **Betriebsausgaben** (freiberuflich/Gewerbe), mindern sie die
Steuerlast; das ist der einzige reale Rückfluss ohne Pflicht (Liebhaberei-Grenze
beachten).

## G. Altgerät
XPS 13 nach Ersatz verkaufen (~100–200 €).

## H. Was **nicht** passt (trägt Pflicht)
Prototype Fund, Fellow-Programm Freies Wissen, NLnet NGI Zero (Open-Source-
**Release**); OpenAI Researcher Access, Anthropic AI for Science, Sloan, Mozilla,
Shuttleworth (**Publikation**/öffentliche Wirkung).
