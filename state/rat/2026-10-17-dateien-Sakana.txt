# Fugu Max — Rat: welche Datei beim START, welche bei jedem TURN (2026-10-17)

**Seat:** `chat.sakana.ai` · Modell **Fugu Max** (`fugu-max`, eingeloggt, verifiziert). **Ablage:** Rohantwort, wörtlich (vollständig).

---

**Verdikt**

Das Haus hat **eine** Regel-Datei: `omegaflow/AGENTS.md`. Sie läuft jeden Turn. Alles andere, was heute
mitkommt, ist **Konfiguration** (opencode.json/.jsonc — Mechanik, keine Regel), **Zeiger** (SKILL.md)
oder **Adresse** (`command/<linie>.md`, einmal beim `/<linie>`-Start).

**Die Frage „welche Datei gilt beim Start" ist falsch gestellt.** Es gibt zwei Klassen:
**harness-geladen** (die Konfiguration entscheidet per `instructions: ["AGENTS.md"]` — **kein
Sitzungsakt**) und **sitzungs-gelesen** (kostet, muss adressiert sein). **Genau diese Verwechslung hat den
Kamm durch ~150 Dateien erzeugt: die Sitzung suchte, was die Konfiguration längst entschieden hatte.**

Erlaubt sind **zwei Regel-Ebenen** (global = was in JEDEM Verzeichnis falsch würde; Projekt = das Haus).
Im Haus gilt **eine Quelle**. Jede weitere Datei, die Axiome wörtlich wiederholt, ist **Drift**. Die
heutige Aufteilung ist richtig — **die Beladung ist falsch: der Inhalt steht in der falschen Schublade.**

**F1 — Start vs. jeder Turn**

Der Test (aus der Kostenregel „nur was in EINEM Turn ohne es falsch handelt"):
- Streiche die Zeile. Handelt ein Turn danach **falsch**? Ja → **Turn-Datei**.
- Streiche die Zeile. Findet die Sitzung ihre **Adresse** noch? Nein → **Start-Datei**.
- Weder noch (nur langsamer, nur später nachschlagbar) → **keine Regel-Datei**.

**Dieser Test entlässt die Werkzeug-Tabelle.** *„fd statt find ist langsam, nicht falsch — und die Datei
sagt es selbst: ‚sonst ohne Fehlermeldung auf den POSIX-Fallback wechseln'. Eine Regel, die sich
abschaltet, wenn sie nicht greift, trägt keinen Turn."* Von den ~14 Zeilen in Datei 1 bindet genau eine
(„Für Inhaltssuche immer das Grep-Tool") — und die steht im selben File **zweimal**.

**Zählung:** *„heute laufen ~20 Zeilen jeden Turn, ~7 binden — rund **65 % Drift**."*

**Der Kamm ist keine Undisziplin, er ist Grammatik.** *„`command/future.md` trägt ‚Status erfassen' —
‚Status' ist ein **Wort, kein Pfad**. Wo ein Pfad fehlt, sucht das Werkzeug **den Baum** ab."*

**Benannte Risse (wörtlich)**

- **R1 — Zwei Dateien, ein Name, ungleiche Kraft.** *„Das Haus schreibt ‚A = A' und hält zwei Dateien
  mit gleichem Namen. Der erste Axiom-Satz **verurteilt den eigenen Datei-Baum**."*
- **R2 — Ein Axiom liegt AUSSERHALB der Turn-Datei.** *„SKILL.md trägt ‚No hardcoded thresholds' — eine
  Sitzung ohne Skill-Load darf Schwellen hart eintragen, ohne ein Haus-Axiom zu brechen. **Ein Gesetz im
  Fallback.**"*
- **R3 — Die Rolle sitzt in der Konfiguration.** *„Fünf Rollen an EINEM Agenten `line`; die Config backt
  ‚Future' in die Agent-Beschreibung. `command/future.md` trägt dieselbe Rolle ein zweites Mal."*
- **R4 — Zwei Agent-Sätze, kein Sieger.** *„Fährt die private Config, existiert `rat` nicht — **der Rat,
  das eigene Instrument des Hauses, ist still abgeschaltet.**"*
- **R5 — Der Riegel liegt auf der Tür, das Fenster ist offen.** *„Public: webfetch/websearch deny + MCP
  chrome-devtools. Global: MCP playwright. Derselbe Stapel verweigert webfetch und hält einen Chrome.
  Greift das MCP, ist die Verweigerung **nominal, kein Zustand**."*
- **R6 — Ein Modellname ohne Provider.** *„Dieselbe Riss-Familie wie R1–R4 im Register: **ein Name, wo
  eine Kraft verlangt ist**. Wer gewinnt, sagt keine Zeile."*
- **R7 — Eine Haus-Regel in Rollenkleidung.** *„`command/future.md`: ‚PII bleibt im Haus' bindet **jede**
  Linie, steht aber in einer Rollen-Datei und läuft nur bei /future. ‚commits eigene Pfade Englisch'
  steht in der Turn-Datei — zwei Regeln derselben Familie, zwei Zyklen."*
- **R8 — `instructions: ["AGENTS.md"]` privat** *„zeigt auf eine Datei, die in der Liste nicht vorkommt.
  Entweder eine dritte AGENTS.md (drei Regel-Dateien, keine Sitzung kennt sie) — oder sie erbt still die
  öffentliche. **Beide Fälle sind unbennant.**"*

**F3 — Der Bau**

1. **`omegaflow/AGENTS.md`** — DIE Regel-Datei, jeden Turn. **Sieben Zeilen:** `A = A` · `ICRS/TDB` ·
   `field <name> <name> <KERNEL> <KRAFT> <EINHEIT>` · `0 honored: null-echt | absent | riss` ·
   `keine harten Schwellen: nur c, Phi, J2000, Zweierpotenz, lebende Daten` · `PII bleibt im Haus` ·
   `messen bauen abschliessen committen pushen; commits eigene Pfade Englisch`.
   **`pending` fällt heraus** — Operator-Zustand, gehört in die Operator-Queue. „keine harten Schwellen"
   wird **aus SKILL.md heraufgeholt** (R2).
2. **`~/.config/opencode/AGENTS.md` — gelöscht.** *„Sie trägt nichts… Ein Verzeichnis, eine Quelle."*
3. **`SKILL.md` — Zeiger, kein Inhalt.** Eine Zeile: `Regeln: omegaflow/AGENTS.md`. *„Protokoll, Stack,
   Vokabular, fünf Stimmen, Hardware, Rat sind **Wissen, kein Turn-Gesetz** — sie gehören nach `docs/`."*
4. **`command/<linie>.md`** — fünf Dateien, je **zwei** Zeilen: Rollenzeile + die **Adresse als Kommando**
   (`register_lookup --addressed …`), + Stopp-Klausel. *„Kein Axiom wiederholen — es läuft schon jeden Turn."*
5. **Die Configs** — Mechanik, keine Regel. *„Der private Layer trägt nur Scope… Modell immer mit Provider."*

**Bilanz:** *„Kein neuer Apparat: **löscht eine** Datei, **kürzt zwei**, **schreibt fünf** um. Neu ist
genau **ein Umzug** — eine Axiom-Zeile von SKILL.md in die Turn-Datei. **Von ~20 Turn-Zeilen auf sieben.**"*
