# Kontrakt — Linie → Leitstelle (2026-10-18)

1. **„Operator" ist kein Adressat.** Was eine andere Linie entscheidet → Token + Brief an `future`.
   Was messbar ist → selbst messen. Nur Ereignis-Waits bleiben im `## Offen`.
2. **Architektur nur als Formular:** Frage · Befund mit `datei:zeile` · Optionen A/B/C · Grenze.
   Keine Prosa-Zeile als Arbeitspunkt.
3. **Kein `pending` ohne Träger + Gate.** Jeder offene Punkt nennt Datei, Token oder Befehl.
4. **Jeder Token endet** echoed im Handover oder `CLOSED` im Ledger.
   Ziel: `register_lookup --tokens` → 0 unbeglichen.
5. **Handover ≤ 1 KiB.** Geschlossenes (Token, Transport) gehört in git, nicht ins lebende Blatt.
6. **Jeder Brief:** `## Fertig, wenn` mit prüfbarem Befehl — kein Platzhalter.
7. **Ein Punkt = ein Zeiger** (`datei:zeile` oder Befehl), keine Erzählung.
